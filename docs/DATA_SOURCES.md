# Data sources

| Data | Source | Licence | How it is used |
|---|---|---|---|
| PIN codes, post-office localities, districts, postal divisions, states (`backend/data/pincodes.csv.gz`, 156,936 rows, 1.1 MB) | India Post "All India Pincode Directory till last month", published on data.gov.in (https://data.gov.in/resource/all-india-pincode-directory-till-last-month). Copy taken from the GitHub mirror github.com/dropdevrahul/pincodes-india (`pincode.csv`, 157,126 rows), downloaded 28 Oct 2026. The older data.gov.in file `pincode_30052019.csv` was rejected: it lacks the Uttar Pradesh, Uttarakhand and West Bengal postal circles. | Government Open Data License – India (GODL-India): free use with attribution. The mirror repo itself is MIT-licensed. Attribution: "Source: India Post, Department of Posts, via data.gov.in." | Trimmed to pin, locality (office name without B.O/S.O/H.O), district, sub-region (postal division) and state; title-cased. Offline lookup for sign-up location (`app/services/location.py`). |
| AICTE region of each state | Not confirmed. aicte-india.org could not be reached from the build machine on 28 Oct 2026. Rows come from an AICTE Western Regional Office page (Maharashtra, Goa, Dadra & Nagar Haveli and Daman & Diu) and an older state-by-region table (indiastat, about 2010). States in neither source (Telangana, Ladakh, Lakshadweep, the North-Eastern states) are marked **confirm**. | – | Admin → "AICTE region for each state" edits any row; every change is in the audit log. Confirm against AICTE's current regional-office jurisdictions before real use. |
